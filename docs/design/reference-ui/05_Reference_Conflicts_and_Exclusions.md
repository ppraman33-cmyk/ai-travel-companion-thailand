# Reference Conflicts and Exclusions

## Resolved authority conflicts

- Screen 15 controls Attraction Detail; Screen 10 contributes only compatible sections.
- Primary navigation is Home, Explore, AI, Saved, Profile. Trips remain contextual.
- Saved uses Dashboard → List/Collection → Detail.
- Profile uses secure anonymous Travel Profiles.
- Prompt and the Founder-approved token palette supersede alternative type and color plates.

## Excluded reference concepts

- Internal turn-by-turn navigation from Screen 28
- Live or provider-backed AI
- Premium, Membership, Points, Payment and registered-account Logout
- Partner, Billing, Sponsored, Campaign, Promotion and commercial ranking
- Hotel booking, delivery and unapproved contact actions
- Unverified Emergency numbers, locations or calls
- Reference photography, mascot artwork, maps, geometry and factual counts

## Safety interpretations

- Directions use trusted Google Maps or Apple Maps links after confirmation.
- Ratings, reviews, hours, prices, event occurrences and contacts are unavailable unless backed by publication-eligible evidence.
- Emergency cards expose verification and freshness states and fail closed.
- Synthetic examples are visibly labelled and never enter production publication states.
- Desktop designs preserve mobile hierarchy instead of inventing a separate information architecture.
