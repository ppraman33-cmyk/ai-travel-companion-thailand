## Future production-media record

Every production asset requires source URL, provenance, owner, license, usage restrictions, verification record and association with a publication-eligible catalog record. Missing or expired evidence suppresses the asset. AI-generated imagery may be decorative only and cannot represent a real place deceptively.

No external media search, download or import is authorized by this program.
